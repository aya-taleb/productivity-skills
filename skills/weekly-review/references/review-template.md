# Weekly review file layout

Save as `weekly/<YYYY>-W<WW>.md` in the founder folder. Keep the headings the same every week,
because next week's review reads the focus lines from this file.

```markdown
# Week 2026-W43 (Oct 19 to Oct 25)

## Last week's focus
- quizpal: Ship the paywall test to 50 users. Done / Not done / Partly: <one line>
- corner-lunch: Sign 2 new offices. ...
- Overall: quizpal. ...

## quizpal
- Wins: <done tasks and what the user said>
- Numbers: signups 212, paid 31  (or {{signups this week}})
- Slipped: <overdue tasks, focus that didn't happen>
- Focus next week: <one checkable outcome>

## corner-lunch
- Wins:
- Numbers:
- Slipped:
- Focus next week:

## Overall
- Focus next week: <business>, because <one sentence>. <Other business> runs at maintenance.
- Revisit: <decision> (revisit date <date>)
- Carry or drop: <overdue tasks waiting for a call>

## Notes
<anything the user said that next week's review should see>
```

Rules for the file:
- Focus lines start with `- <slug>:` or `- Focus next week:` so they are easy to find next week.
- Dates are absolute (2026-10-30), never "next Friday".
- Placeholders stay in `{{double braces}}` until the user gives the number.
